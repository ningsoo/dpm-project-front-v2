# 저장 폴더 (Saved)

이 폴더에는 **이미지**와 **코드/데이터 파일**을 넣어 두고 프로젝트에서 불러 쓸 수 있습니다.

## 이미지 사용 방법

- 이 폴더에 이미지 파일(예: `photo.png`, `banner.jpg`)을 넣으면
- 웹에서 **`/saved/파일명`** 경로로 접근할 수 있습니다.
  - 예: `https://도메인/saved/photo.png` 또는 `<img src="/saved/photo.png" />`

## 코드/데이터 파일

- JSON, 텍스트 등도 이 폴더에 넣을 수 있습니다.
- 필요하면 `fetch('/saved/데이터.json')` 처럼 불러와서 사용하면 됩니다.

이제 이 폴더에 이미지나 파일을 넣어 두시면 됩니다.
